# Телефонная книга на Tkinter

## Описание проекта
Это простое GUI-приложение для управления контактами. Программа позволяет добавлять, просматривать, искать и удалять контакты через удобный интерфейс на Tkinter. Все данные сохраняются в файл `contacts.json`, поэтому контакты не пропадают после закрытия программы.

Проект подходит для учебных задач по Python, работе с Tkinter, списками, словарями и сохранением данных в JSON.

## Возможности
- Добавление нового контакта.
- Просмотр списка контактов.
- Удаление контакта.
- Поиск контакта по имени.
- Сохранение данных между запусками.
- Простая и понятная графическая оболочка.

## Требования
Для работы программы нужен:
- Python 3.10 или выше.
- Установленный модуль Tkinter.
- Файл `contacts.json` (создаётся автоматически при первом сохранении).

## Инструкция по запуску
1. Откройте проект в VS Code.
2. Сохраните файл программы, например как `phonebook.py`.
3. Убедитесь, что рядом с ним находится файл `contacts.json` или программа сможет создать его сама.
4. Запустите программу командой:

```bash
python phonebook.py
```

Если у вас несколько версий Python, можно использовать:

```bash
python3 phonebook.py
```

## Структура проекта
- `phonebook.py` — основной файл программы.
- `contacts.json` — файл для хранения контактов.
- `README.md` — описание проекта.

## Как работает программа
1. Пользователь вводит имя и номер телефона.
2. Нажимает кнопку «Добавить контакт».
3. Контакт появляется в списке и сохраняется в файл.
4. Для поиска нужно ввести имя в поле поиска и нажать кнопку «Поиск».
5. Чтобы удалить контакт, нужно выбрать его в списке и нажать «Удалить».
6. После перезапуска программы все ранее сохранённые данные остаются.

## Примеры использования
### Добавление контакта
- Имя: `Иван`
- Номер: `+37060000000`
- Результат: контакт появляется в списке и записывается в `contacts.json`.

### Фильтрация контактов
- В поле поиска вводится, например, `ан`.
- В списке остаются только контакты, в имени которых есть эта часть текста.

### Удаление контакта
- Пользователь выделяет контакт в списке.
- Нажимает кнопку «Удалить».
- Контакт исчезает из списка и удаляется из файла.
